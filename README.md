# Ali Moner Diop — Premium Motion Portfolio

English / Arabic, dark interactive portfolio for GitHub Pages.

## Publish to existing GitHub repository
1. Unzip this package.
2. In `alimonerdiop-sketch/portfolio-`, upload **the contents** of this folder to the root (not the ZIP).
3. Replace `index.html`, `styles.css`, `app.js`, and retain/upload the full `assets/` folder. Add `robots.txt` and `sitemap.xml`.
4. Commit changes. Keep GitHub Pages settings on `main / (root)`.
5. View https://alimonerdiop-sketch.github.io/portfolio-/?v=2 and hard refresh if needed.

## Contents and features
- 6 user-supplied YouTube Shorts IDs in `app.js`; thumbnails fetched from YouTube, iframe loaded only on click.
- `assets/ali-portrait.webp` is the owner-provided photo.
- Bilingual EN / AR, RTL switching, reduced-motion support, keyboard-accessible video dialog.
- SEO: canonical, Open Graph/Twitter, Person structured data, sitemap, robots.
- Contact: WhatsApp, email, Instagram.

YouTube thumbnails and embeds depend on YouTube availability and embedding permissions. Social preview caches can take time to refresh.
