# Ali Moner Diop — Dark Motion Portfolio (YouTube Edition)

Static English/Arabic portfolio for free GitHub Pages hosting. Dark motion design, personal portrait, six YouTube Shorts embedded directly in an on-site dialog.

## Publish update to your existing repository

1. Open https://github.com/alimonerdiop-sketch/portfolio-
2. Upload / replace **index.html**, **styles.css**, **app.js** at the repository root. Use **Add file → Upload files** and confirm replacement of existing files.
3. Keep / upload `assets/ali-portrait.webp` so the portrait displays. This ZIP includes the complete assets folder as well.
4. Commit the changes. Settings → Pages should be configured to deploy `main` from `/(root)`.
5. Visit https://alimonerdiop-sketch.github.io/portfolio-/ and press Ctrl+F5 to refresh.

## Videos

Cards use real YouTube thumbnails (`maxresdefault.jpg` with fallback to `hqdefault.jpg`). Clicking the center play icon opens a vertical YouTube embed on the same page. Videos must allow embedding; YouTube UI and availability are controlled by YouTube. No MP4 video hosting on GitHub is necessary.

The thumbnail is intentionally center-cropped to fit a landscape card. To alter the crop or use a custom cover, edit the image and styles as needed.

Contact and bilingual content are retained from the previous version.
