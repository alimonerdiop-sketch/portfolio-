# Ali Moner Diop — Dark Motion Portfolio (Video Thumbnails Update)

A static, bilingual (English/Arabic) video editing portfolio ready for GitHub Pages. The dark design and motion interactions are preserved from the approved version.

## Preview thumbnails

The six project cards now attempt to display actual Instagram post previews, rather than abstract placeholder artwork.

Preview fallback order:

1. `assets/thumbs/project-01.webp` through `assets/thumbs/project-06.webp`, if provided (recommended, **reliable**).
2. A preview image exposed by Instagram's public post media endpoint, when available.
3. An embedded preview of the real Instagram post, when permitted by Instagram.
4. A clean dark fallback with a link to watch on Instagram, if embedding is unavailable.

**Important:** Instagram limits automated access, hotlinking and embedding in some cases. No remote thumbnail method is guaranteed across every browser. For guaranteed thumbnails, export or screenshot one frame from each of your six videos, and place it in the `assets/thumbs` folder using the names above. Replace the files only: no code changes are required. The website does not invent thumbnail images.

### Recommended still size

Save WebP stills at **1200 × 900 px** (landscape card, crops a vertical reel to the card). To preserve the full portrait cover, use a 9:16 still; it will be center-cropped automatically.

### Install / publish

Unzip, open `index.html` to preview, or upload all files to a GitHub public repository and enable Settings → Pages → Deploy from branch → main / root. The site uses no paid hosting, build tools, or API keys.
